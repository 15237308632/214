# 05 · 《穷通宝鉴》

> 五书中唯一一本「辞典」。它不问格局、不论旺衰强弱，只问一件事：**这个日干，生在这个月的气候里，最需要哪几个天干来搭配**。

## 一、文献卡片与书名流变

| 项 | 内容 |
|---|---|
| 原名 | 《栏江网》（「横江置网，一网打尽」之意），明末民间抄本，作者与著作年代不详 |
| 蓝本 | 一说依《三命通会》卷十一「五行时地分野」为主；书中多举明代名人命例，故一般定为明末 |
| 清初 | 传入日官之手，易名《造化元钥》 |
| 清末 | 楚南**余春台**整理、归纳、刊行，更名《穷通宝鉴》 |
| 民国 | 徐乐吾增补评注，成《造化元钥评注》 |
| 体例 | 不分卷，辞典体：十天干 × 十二月令，逐月列调候用神与取用理由 |
| 定位 | 命理五经之一；首次系统提出「**调候**」论命法，调候派圭臬 |

> 余春台序中说明整理缘由：友人持《栏江纲》善本，「权量人之富贵，往往有验」，遂「细加编辑，视其繁者汰之，略者增之，去其鲁鱼亥豕之讹」，并「更其名曰《穷通宝鉴》」，称「此真命学之指南，子平之模范也」。**《栏江网》《造化元钥》《穷通宝鉴》《造化元钥评注》实为同一系统的不同抄本与整理本**，书名互见，引用时须标明所据版本。

## 二、核心命题：调候为急

1. **调候专论全局寒、热、燥、湿**：冬要暖，夏要润；春宜疏通，秋宜温润。
2. **优先层级（穷通一派主张）**：调候 > 扶抑旺衰 > 格局十神。调候缺失，纵然成格也多波折缺憾；调候到位，再看日主能不能担。
3. **调候与扶抑是两个维度**：调候管气候，扶抑管强弱；二者可以是同一个字，也可以是完全不同的两个字。例：庚金生子月，冬金寒须火调候，金弱又喜土生扶——火是调候，土是扶抑。
4. **调候用神不可重伤**：被合、被克、被冲，谓之「调候受损」，格局再好也留缺憾。
5. **十干物性优先于十神名相**：甲喜庚劈引丁、乙喜丙癸、丙喜壬、丁喜庚甲、戊己喜甲丙癸、庚喜丁甲、辛喜壬己、壬癸喜庚辛——这些搭配里大量出现七杀、伤官等「凶神」，说明书根本不以十神吉凶为取舍。

> 常见勘误：**旺衰不是调候**。旺衰看五行数量多寡，调候看月令气候寒热。冬天水旺依旧要火暖局，夏天火旺依旧要水降温。

## 三、十干喜用的主干搭配（归纳）

| 日干 | 高频搭配 | 物性逻辑 |
|---|---|---|
| 甲 | 庚、丁、丙、癸 | 「用庚劈甲，方引丁火，使得木火有通明之象」；冬须丙，夏须癸 |
| 乙 | 丙、癸 | 「为芝兰蒿草之物，丙癸不可离也」；忌重金 |
| 丙 | 壬、庚 | 太阳喜壬水「日照江河」，庚发水之源 |
| 丁 | 庚、甲、丙 | 庚劈甲引丁，甲为灯芯；忌壬水大水灭烛 |
| 戊 | 甲、丙、癸 | 非甲不灵，非丙不暖，非癸不润 |
| 己 | 丙、癸、甲 | 田园湿土，先暖后润再疏 |
| 庚 | 丁、甲、丙 | 顽金宜丁煅，借甲引丁；冬金须丙照暖 |
| 辛 | 壬、己、丙 | 珠玉喜壬淘洗、己土生身；冬月不能缺丙 |
| 壬 | 庚、辛、戊、丙 | 庚辛发源、戊土堤防、丙火暖局 |
| 癸 | 辛、庚、丙 | 雨露喜辛生、丙解冻 |

梁湘润曾据《穷通宝鉴》做提要表，统计甲木十二月喜用中**庚金出现 11 次、丁火 11 次**，丙癸各 5 次——正好说明丙癸主要承担调候，庚丁才是甲木的「元素优化组合」。这个观察是理解全书体例的钥匙。

## 五、四个使用陷阱

1. **套公式化**。它像辞典，「按所引」省时省力，但也最容易生硬照搬；原书对「上半月 / 下半月」「支成水局」「土旺者 / 木旺者」等条件有大量限定，不读条件只抄用神必错。
2. **把调候当唯一标准**。原书不查格局、不论病药、不重地支（藏干须透干方发用），是**有意的单维度视角**。用它否定格局法或旺衰法，属于越界。
3. **丙丁不分**。丙为太阳喜壬水映照，丁为灯烛忌壬水大水、只可微癸；冬月丁火要甲木为芯，不是拿壬水调候。同类还有壬癸、戊己、庚辛之别。
4. **忽略上下半月**。未、酉、丑等月条分上下半月，对应交节前后的司令分野，实务须结合交节时刻（本库 `tiaohou.json` 已在 meta 中标注）。

## 六、优先级异说（本库不代裁）

| 主张 | 出处 / 立场 |
|---|---|
| 调候 > 扶抑 > 格局 | 穷通一派，以《穷通宝鉴》为圭臬 |
| 调候纳入格局体系，不另立最高级 | 《子平真诠》卷二第 14 篇「论用神配气候得失」 |
| 寒暖燥湿为理气之一章，仍须随局顺势、不可执一 | 《滴天髓·寒暖》《燥湿》与任注病药说 |

> 三说并列。实务中须**显式声明**采用哪一套为主，并把另两套作校验，不可把三套结论平均。

## 七、与其余四书的关系

- 对《渊海子平》《三命通会》：同用月令气候，但那两书收而未专，本书专而成表。
- 对《子平真诠》：真诠在十神搭配上论日元所处环境，穷通在**天干物性搭配**上论日元所处气候；前者重「名分」，后者重「物性」，且穷通不重地支。
- 对《滴天髓》：都由寒暖燥湿出发，但滴天髓反辞典化，强调随局、顺势、不可执一。
