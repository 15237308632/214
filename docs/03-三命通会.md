# 03 · 《三命通会》

> 这不是一本「提出新理论」的书，而是一部**总汇**。它的价值在资料完整，风险也正在于资料太全。

## 一、文献卡片

| 项 | 内容 |
|---|---|
| 书名 | 三命通会 |
| 年代 | 明·万历六年（1578）前后 |
| 作者 | 明·万民英（进士） |
| 卷帙 | **十二卷** |
| 地位 | 传统命理集大成之作；**唯一被《四库全书》收录**的命理著作（子部术数类） |
| 规模 | 约六十万字；一说收 1200 余命例 |
| 版本异说 | 通行本十二卷；前九卷为子平本法，后三卷多存古法歌赋，风格不一，或为后学增辑，各坊本卷次编列略有出入 |

## 二、篇章结构

| 卷 | 内容 |
|---|---|
| 前九卷 | 分列**十天干**，每天干「以日为主，以月为核心，以时为辅」定吉凶；兼论阴阳五行、排法、神煞、格局、命例 |
| 后三卷 | 大量古歌赋、平古歌赋、神煞、纳音与宋以前古法的存录 |

**结构提示**：前九卷与后三卷的落差不是编排失误，而是万民英有意做的「新旧并收」——前九卷是当时通行的子平法，后三卷是即将被淘汰的古法档案。读它时应当带着层位意识：同一本书里同时存在两套判据。

## 三、《四库全书总目》的评价

> 自明以来二百余年，谈星命者皆以此本为总汇，几于家有其书……特以其阐发子平之遗法，于官印、财禄、食伤之名义，用神之轻重，诸神煞所系之吉凶，皆能采撮群言，得其精要，故为术家所恒用，要有未可遂废者。

注意四库馆臣的措辞：**「采撮群言，得其精要」「未可遂废」**——肯定的是资料价值与折衷功夫，不是理论原创。这个评价至今仍是最准确的定位。

## 四、核心命题

1. **集大成**：总结八字推命几百年的发展，去芜存菁，并把宋以前的古法与后世子平法做了较详细的对照总结。
2. **以日为主、月为核心、时为辅**：把日干中心与月令优先明确写成编排原则，可视为《渊海子平》到《子平真诠》之间的桥梁。
3. **十神名义与用神轻重**：于官印、财禄、食伤之名分，用神之轻重，采撮群言——这是后世格局论的术语库。
4. **神煞吉凶并存**：不删古法，使其在传统命学中保有档案价值。

## 五、如何把它当工具书用

| 需求 | 去哪查 |
|---|---|
| 某一神煞的起例与古籍出处 | 后三卷 / 卷中神煞部分 |
| 某日干在某月的古法说法 | 前九卷按十干分列处 |
| 某格局或赋文的原始出处 | 后三卷歌赋 |
| 命例旁证 | 全书散布，含大量明代人物八字 |
| 与子平新法的对照 | 前九卷 ↔ 后三卷并读 |

> 实务建议：把它当**词典与语料库**，不要当判局流程。判局流程应取《子平真诠》或《滴天髓》其一为主，用《三命通会》查术语源流与命例。

## 六、与其余四书的关系

| 对手 | 关系 |
|---|---|
| 渊海子平 | 《三命通会》收录并保存了《渊海子平》一系的子平法，也保存了更古的纳音法 |
| 子平真诠 | 真诠把「以月为核心」推到极致（专求月令），并剔除神煞层；《三命通会》则是折衷并存 |
| 滴天髓 | 任铁樵所力斥的神煞、奇格、纳音，恰是《三命通会》后三卷的主要内容，构成最鲜明的对照 |
| 穷通宝鉴 | 一说《栏江网》蓝本与《三命通会》卷十一「五行时地分野」有关；两书都按月令气候立论，但《三命通会》收而未专，《穷通宝鉴》专而成表 |
| 子平真诠版本考 | 清钞本《耕寸集》命例多摘录自《子平三命通变渊源》与《三命通会》，故可据以推断《子平真诠》前身成书在万历六年之后 |

## 七、常见误读

1. **误读一：把「集大成」当「最正确」**。博收意味着并列矛盾说法，需要读者自己分辨层位，书本身不作裁决。
2. **误读二：忽略后三卷的古法属性**。用后三卷的纳音 / 神煞去否定前九卷的十神格局，或反过来，都是层位错置。
3. **误读三：以为四库收录等于官方背书其术**。《四库提要》全文语气是「存其书以备一家」，末句「要有未可遂废者」是文献保存意义上的肯定。
4. **误读四：拿它当入门教材**。六十万字体量、术语古今混杂，更适合作为查考用的第二本书。
