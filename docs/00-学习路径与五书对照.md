> 本库把五书视为**五种不同的提问方式**，而不是一本大部头拆成的五册。先建立坐标，再读细节。

## 二、三条判局坐标系（务必分清）

```
《子平真诠》  月令 → 格局 → 用神 → 相神 → 成败救应   [结构 / 名分]
《滴天髓》    气势 → 衰旺 → 中和 → 病药 → 流通        [能量 / 动态]
《穷通宝鉴》  月令气候 → 十干物性 → 天干搭配          [环境 / 物性]
```

三者对同一个八字可能给出**不同的用神**。例如「甲木生子月」：

- 真诠一路：月令子中癸水为印，取印格，看是否透、是否被财破、有无官煞相生。
- 滴天髓一路：冬水寒凝，看全局气势是否流通，寒甚须暖，不拘财官印绶皆可为用。
- 穷通一路：**专用丙火**解冻，「冬木无丙万事空」，先解决气候，再谈其余。

> 这不是矛盾，而是分辨率不同。资深做法是先声明主用哪一套，再把另两套作为**校验与补充**，而不是把三套结论平均。

## 四、最常见的五个混用陷阱

1. **把「用神」当一个固定术语**。真诠的用神是「月令所定之格」，滴天髓的用神是「治局之病之药」，穷通的用神是「调候所需之干」。同词异义，混用即错。
2. **把旺衰当调候**。旺衰看五行数量与得令，调候看月令寒暖。冬月水旺仍须火暖，夏月火旺仍须水润，两者可以指向完全不同的字。
3. **把四吉神四凶神当道德标签**。真诠卷二紧接「论四吉神能破格」「论四凶神能成格」两篇，正是为了防止这种读法。
4. **以神煞定格局**。真诠「论星辰无关格局」、任铁樵力斥神煞；而渊海、三命通会里的神煞属另一层位。用古法层位的东西去改子平层的结论，是层位错置。
5. **以长生十二宫硬断旺衰**。任铁樵明言长生沐浴为假借形容之辞；阴干逆行、土寄火宫本身就有异说（见 `06`）。

## 五、阅读检验（自测）

读完五书笔记后，应能不加检索地回答：

- 真诠「八字用神，专求月令」下一句是什么？为什么「不向月令求用神」被斥为「执假失真」？
- 滴天髓「衰旺」篇说的「旺之极者不可损」与一般扶抑法冲突在哪里？
- 《穷通宝鉴》为何说甲木「用庚劈甲引丁」？这与十神里庚为七杀、丁为伤官的「凶神」标签如何并存？
- 《三命通会》前九卷与后三卷为何风格不同？这对「集大成」意味着什么？
- 子平真诠卷三「论星辰无关格局」与《渊海子平》卷一广列神煞，是互相否定，还是层位不同？
