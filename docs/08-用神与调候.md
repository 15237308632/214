# 08 · 用神与调候：一个词，三种意思

> 「用神」是整部子平文献里最容易出错的词。**五书都在说用神，但说的不是同一件事。** 本篇先拆词义，再讲调候。

## 一、用神三义对照

| | 《子平真诠》 | 《滴天髓》 | 《穷通宝鉴》 |
|---|---|---|---|
| 用神指什么 | **月令所定之格**（财官印食煞伤劫刃） | **治局之病的药** | **调候所需之天干** |
| 怎么取 | 专求月令，看藏干透干 | 辨病：偏旺则抑、偏弱则扶、寒则暖、燥则润 | 按日干 × 月令查表 |
| 是否固定 | 相对固定（由月令定） | 随局而变，不拘财官印绶皆可为用 | 按条目相对固定 |
| 与其他字关系 | 相神护格 | 源流、通关、清浊、真假 | 候用神不可被合克冲伤 |
| 对吉凶名分 | 顺用 / 逆用 | 吉凶相对，随喜忌而转 | 不看十神吉凶，只看物性搭配 |

> 徐乐吾在《子平真诠评注》里说「用神者，八字中所用之神也……所取用神未真，命无准理，故评命以取用神为第一要义」，这是**评注者**的通称，已把三义熔为一炉。读原文时仍须分开。

## 二、五种取用法（徐乐吾归纳，非原著次第）

《子平真诠评注·论用神》把取用约为五类：

| 法 | 内容 | 对应经典 |
|---|---|---|
| 扶抑 | 日元强者抑之（官煞克、食伤泄），弱者扶之（印生、劫助）；月令之神太强则抑、太弱则扶 | 旺衰派、《滴天髓》衰旺篇 |
| 病药 | 以扶为喜，则伤其扶者为病；除病之字为药 | 《滴天髓》任注、《神峰通考》「有病方为贵」 |
| 调候 | 金水生于冬令、木火生于夏令，寒燥太甚，以调和气候为急 | 《穷通宝鉴》、真诠第 14 篇 |
| 专旺 | 气势偏于一方不可逆，惟顺其势：从、化、一方专旺 | 《滴天髓》从象化象顺局 |
| 通关 | 两神对峙、强弱均平，须调和之使气势续而不战 | 《滴天髓》源流、通关 |

**关键限定**（徐注）：「各称善恶，无关吉凶。为我所喜，枭伤七煞，皆为吉神；犯我所忌，正官财印，同为恶物。」——吉凶完全相对化。

## 三、病药说

任铁樵《滴天髓阐微》把命局比作人身、气势比作病象：

- 偏旺 → 抑；偏弱 → 扶；寒 → 暖；燥 → 润；浊 → 清；塞 → 通。
- 「不能辨其病，则补救无从着手；误判病药，反致破局。」
- 与「中和」互为表里：中和是目标，病药是手段。但原文自己承认「偏气古怪，亦取富贵，不必于中且和也」，所以中和不是教条。

**《滴天髓·衰旺》对机械扶抑的修正**：

> 旺之极者不可损，以损在其中矣；衰之极者不可益，以益在其中矣。

极处自有反转，再加减反凶。这是「病药」区别于「数数量补强弱」的分水岭。

## 四、调候：120 条提要的结构

`data/tiaohou.json` = 10 日干 × 12 月令（寅起立春至丑起小寒），共 **120 条**通行本原文提要。

**主干规律**（便于记忆，但不能代替原文）：

```
冬月(亥子丑)  寒 → 先寻丙火解冻，丁火为辅，庚甲佐之
夏月(巳午未)  燥 → 先寻壬癸水润局，庚辛发水源
春月(寅卯辰)  余寒 / 湿土 → 丙火暖，癸水润，庚金疏
秋月(申酉戌)  金旺转凉 → 丁火制金暖木，丙火调候
```

**十干物性组合**（《穷通宝鉴》真正的核心，不是十神）：

| 日干 | 主搭配 | 名句 / 逻辑 |
|---|---|---|
| 甲 | 庚、丁 | 「先用庚劈甲，方引丁火，使得木火有通明之象」 |
| 乙 | 丙、癸 | 「为芝兰蒿草之物，丙癸不可离也」 |
| 丙 | 壬、庚 | 太阳得壬「日照江河」，庚发水之源 |
| 丁 | 庚、甲 | 庚劈甲引丁，甲为灯芯；忌壬水灭烛 |
| 戊 / 己 | 甲、丙、癸 | 非甲不灵，非丙不暖，非癸不润 |
| 庚 | 丁、甲 | 顽金宜丁煅，借甲引丁 |
| 辛 | 壬、己 | 珠玉喜壬淘洗、己土生身 |
| 壬 / 癸 | 庚、辛（壬兼戊、癸兼丙） | 发水源 / 丙火解冻 |

> 梁湘润统计甲木十二月喜用中庚、丁各出现 11 次，丙、癸各 5 次——**丙癸主要承担调候，庚丁才是甲木的元素优化组合**。这正是「凶神也能为用」的实证：庚为七杀、丁为伤官，在十神名分上是「凶」，在物性搭配上却是首选。

## 五、调候的四个陷阱

1. **套公式**：原书对「上半月 / 下半月」「支成水局」「土旺者 / 木旺者」「通根巳寅」等有大量条件限定，只抄用神必错。
2. **越界否定他法**：本书有意不查格局、不论病药、不重地支（藏干须透干方发用），是**单维度视角**，不能用来否定格局法或旺衰法。
3. **丙丁不分、壬癸不分**：丙喜壬，丁忌壬只可微癸；冬丁要甲木为芯，不是拿壬去调候。
4. **忽略交节**：未、酉、丑等月分上下半月，须结合交节时刻。

## 六、优先级异说（本库并列，不代裁）

| 主张 | 出处 |
|---|---|
| **调候 > 扶抑 > 格局** | 穷通一派（「调候为急」，寒暖燥湿失宜，格局虽成亦多缺憾） |
| **调候纳入格局之内**，不另立最高级 | 《子平真诠》卷二第 14 篇「论用神配气候得失」 |
| 寒暖燥湿为理气之一章，仍须随局顺势、不可执一 | 《滴天髓·寒暖》《燥湿》与任注病药说 |

实务规则：**显式声明主用哪一套**，另两套只作校验，不把三套结论平均。引擎 `analyze()` 的「判局次序」字段即按此顺序输出，并在每一步标注出处。

## 七、用神的变化、纯杂与因成得败

《子平真诠》卷二用四篇处理「用神不是静态的」：

- 第 10 篇 **论用神变化**：透干不同、位置不同，格局随之变化。
- 第 11 篇 **论用神纯杂**（附清气、浊气）：用神纯则清，杂则浊；与《滴天髓》清浊专章互参。
- 第 12 篇 **论用神格局高低**：有情无情、有力无力。
- 第 13 篇 **论用神因成得败、因败得成**：成格之局因岁运或某字而败，败格之局因救应而成。

**喜忌干支有别**（第 27 篇）与**支中喜忌逢运透清**（第 28 篇）：天干之喜忌与地支之喜忌作用方式不同；地支所藏之喜忌，须待岁运透清方显。这是「原局 → 岁运」的接口。
