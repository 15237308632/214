# 02 · 《滴天髓》

> 五书里最短、最难、也最「现代」的一本。它把命理从「查神煞、套格局」拉回到**五行的动态平衡**，因此成为旺衰 / 理气一派的圣典。

## 一、文献卡片与版本迷宫

| 项 | 内容 |
|---|---|
| 原著 | 旧题宋·京图撰；一说明初刘基（刘伯温）作 / 注 |
| 原文 | 七言诗体，约三千余字 |
| 关键注本 | 清·任铁樵《滴天髓阐微》（道光年间成书，民间流传最广）；徐乐吾《滴天髓征义》；另有《滴天髓辑要》 |
| 通行结构 | 孙衡甫刊《阐微》四卷，分《通神论》34 章、《六亲论》29 章，合 **63 章**，任氏引 **512 个命例** |
| 体例 | 「原文 — 原注（刘基）— 任氏曰 — 命例」四段式 |
| 版本异说 | 篇章标题与分卷各本互异，卷次多为后人整理，非原书定制；钟义明曾批评孙衡甫刊本编辑「琐碎割裂，如串珠断线」，而徐乐吾《征义》四卷（通神颂 / 形象格局 / 体用精神 / 征验）体系较完整 |

**读法建议**：把「原文三千字」「刘基原注」「任铁樵阐微」当成三个不同的文本层。任注虽托名阐发，实际自成体系，且与刘注「观点多相悖」。

## 二、篇章结构（据《阐微》通行本）

**《通神论》34 章**：天道、地道、人道、知命、理气、配合、天干、地支、干支总论、形象、方局、八格、体用、精神、月令、生时、衰旺、中和、源流、通关、官杀、伤官、清气、浊气、真神、假神、刚柔、顺逆、寒暖、燥湿、隐显、众寡、震兑、坎离。

**《六亲论》29 章**：夫妻、子女、兄弟、何知章、女命章、小儿、才德、奋郁、恩怨、闲神、从象、化象、假从、假化、顺局、反局、战局、合局、君象、臣象、母象、子象、性情、疾病、出身、地位、岁运、贞元。

> 注意：《六亲论》里塞进了大量非六亲内容（从化、战局、君臣象等），这正是版本编辑被诟病之处。按「条目次第」理解比按「卷次」更稳妥。

## 三、八个核心命题

1. **以气为先**。吉凶不在某一神煞、某一字，而在全局气势是否**流通、中和、得时得地**。任氏明确反对只数五行多寡。
2. **衰旺真机**。「旺之极者不可损」「衰之极者不可益」——极处自有反转，这是对机械扶抑法最直接的修正。
3. **中和为要法，但不执中和**。原文一面说「中而且和，子平之要法」，一面承认「偏气古怪，亦取富贵，不必于中且和也」。这是全书辩证性的典型。
4. **病药说**。用神不是固定的吉神，而是针对命局之「病」的「药」：寒则火、燥则水、弱则扶、太过则抑；病未辨而先补，反致破局。
5. **源流与通关**。五行接续相生、天地同流为佳；两神对峙僵持时取通关，使气势续而不战。
6. **清浊、真假、隐显、众寡**。论格局纯杂、用神真伪、气势藏露、势力寡众，都是结构判断而非字面吉凶。
7. **刚柔与顺逆**。刚者不可硬制，须「引其性情」；势已成者「不可逆」，只可顺。这与《子平真诠》以合冲论救应是两种视角。
8. **寒暖燥湿**。「天道有寒暖」「地道有燥湿」，把四时气候正式纳入理气，为后来《穷通宝鉴》一路开了门。

## 四、任铁樵做了什么（一次范式清理）

- **力斥神煞、奇格异局、纳音**，把命理收归五行生克、十干性情、旺衰喜忌。
- **辨长生十二宫**：指出长生沐浴为「假借形容之辞，不可执一」，并借命例辨析阴阳顺逆、生旺死绝。
- **驳拟象失伦**：反对把甲木固定说成栋梁、乙木说成花果，主张干气各有刚柔。
- **以命例验证**：每立一论必援引推验命造，或阐发成法，或匡正时讹；常以相似八字而运途迥异之例，揭示「理气进退」之机。
- **主张「不拘财官印绶，皆可为用」**——用神由局定，不由名分定。

## 五、关键原文辑要

> 以下据通行本《滴天髓》与《滴天髓辑要》，个别字句各本互异，引用时宜版本互校。

**《衰旺》**
> 能知衰旺之真机，其于立命之奥，思过半矣。旺则宜泄宜伤，衰则喜帮喜助……旺之极者不可损，以损在其中矣；衰之极者不可益，以益在其中矣。

前两句是常法，后两句是变法：极旺极衰处，损益已内含于势中，再强行加减反凶。

**《中和》**
> 中而且和，子平之要法。虽曰有病方为贵，无伤不是奇……是必归于中和，乃为至贵。

紧接着又承认「身弱而财官旺也，取富贵不必于中也……偏气古怪，亦取富贵」。同一篇内自我设限，说明它不是教条。

**《刚柔》《顺逆》**
> 刚柔不一也，不可制者，引其性情而已矣。
> 顺逆不齐也。不可逆者，顺其气势而已矣。

「引」与「顺」两个字，是全书最具方法论价值的动词。

**《寒暖》《燥湿》**
> 天道有寒暖，发育万物，人道得之，不可过也。阴支为寒，阳支为暖，金水为寒，木火为暖。得气之寒，遇暖而发；得气之暖，遇寒而成。
> 地道有燥湿……过于湿者，滞而无成；过于燥者，烈而有祸。

**《理气》《干支总论》**（据通行本引）
> 理承气行岂有常，进兮退兮宜抑扬。
> 始其所始，终其所终，富贵福寿，永乎无穷。

任氏举「戊戌 庚申 癸亥 乙卯」「甲子 丙寅 己巳 辛未」两造，共性在于干支接续相生、地载天而天地同流——**流通是达到生克平衡的最好形式**。

## 六、与其余四书的张力

| 对手 | 张力点 |
|---|---|
| 渊海子平 / 三命通会 | 神煞纳音：前者存录，任氏力斥 |
| 子平真诠 | 真诠以月令名分定格；滴天髓以气势定用，弱化十神名相。真诠「论用神配气候得失」把调候纳入格局，滴天髓则把寒暖燥湿列为独立章节 |
| 穷通宝鉴 | 两者都重气候，但穷通落到「某干生某月用某干」的固定搭配，滴天髓仍强调「随局、顺势、不可执一」，反对辞典化 |
| 注本之间 | 徐乐吾评注把「扶抑、病药、调候、专旺、通关」归纳为五种取用法，实际上是用《子平真诠》框架反过来整理《滴天髓》，读时须知这是**民国人的重整**，非原著次第 |

## 七、常见误读

1. **把「身旺身弱」当成滴天髓全部**。衰旺只是其中一篇，且原文自己就限制了机械扶抑。
2. **把任注当原文**。三千字原文与数万字任注不是同一层；任氏与刘基注常相悖。
3. **用旺衰扶抑去解释从化、顺局、反局**。这几类恰恰是「势不可逆、只可顺」的例外区。
4. **忽略版本割裂**。孙衡甫刊本 34+29 章的编排被批评为断章取义、前后颠倒；徐乐吾《征义》结构较完整，两者不应混引。
