# 01 · 《渊海子平》

> 读这本书要记住一句话：**它是子平法的「原貌」，不是今法的「简写本」**。用今天通行的旺衰扶抑去套它，会处处对不上。

## 一、文献卡片

| 项 | 内容 |
|---|---|
| 书名 | 渊海子平 |
| 年代 | 宋；今本为明人合编 |
| 作者 | 题宋·徐大升（一作徐子升）编，渊源为五代宋初徐子平的四柱法 |
| 卷帙 | 五卷 |
| 地位 | 八字推命史上**第一部成系统、成理论**的著作；子平派宗祖 |
| 版本异说 | 宋徐大升原有《渊海》《渊源》二书，明·杨淙合为一帙即今本；「大升 / 子升」二写并存，今本非宋本原貌 |

## 二、篇章结构（五卷）

| 卷 | 主要内容 |
|---|---|
| 卷一 | 阴阳五行基本原理、神煞、纳音、起运、基础排法 |
| 卷二 | 继善篇、正官格等**格局论** |
| 卷三 | 女命、子孙、六亲 |
| 卷四 | 鉴人术、十二月建候 |
| 卷五 | 把前几卷转化为**诗诀、赋诀**，便于记诵 |

这个结构本身就有信息量：**先基础与神煞，再格局，再六亲，最后压成口诀**。说明它处在「古法未褪、新法初立」的过渡期。

## 三、它究竟改变了什么

在徐子平之前，李虚中一系以**三柱（年月日）**、纳音、神煞论命。《渊海子平》确立的转向是：

1. **四柱成型**：加入时柱，年月日时四柱八字成为定式。
2. **以日干为我**：论命中心从年柱 / 纳音移到日主，其余七字围绕日主展开。
3. **财官印食的名分体系**：用十神关系（而非星曜吉凶）把命运层次分为三六九等。
4. **格局法定富贵**：以财官印食等格局论富贵贫贱，取代纳音论命法。

> 因此后世说「论富贵贫贱首推徐子平财官格局法，论生死当属鬼谷子纳音古法」，指的是两条并行的技术路线，而非同一套东西的升级。

## 四、古法残留（读时最容易误判的部分）

《渊海子平》保留了大量**前子平**的内容：

- 神煞体系（卷一）
- 纳音五行
- 各种奇异格局与歌诀

这不是「错」，而是层位不同。清人任铁樵《滴天髓阐微》力斥神煞、奇格、纳音，沈孝瞻《子平真诠》专设「论星辰无关格局」，针对的正是这一层。若拿任氏、沈氏的标准去删改《渊海子平》，等于把文献改写成后人的样子。

**关键判断**：今本《渊海子平》的原始论法与当代通行论法差异相当大，适合作为**源流与术语发生史**来读，不适合当作入门操作手册。初学者更宜先立《子平真诠》的骨架，再回头看它。

## 五、与其余四书的关系

| 对手 | 关系 |
|---|---|
| 三命通会 | 后者把《渊海子平》一系的子平法与宋以前古法**一并收录**，等于替它做了资料总汇 |
| 子平真诠 | 把财官格局法收束到「月令」这一唯一入口，逻辑更严，也剔除了神煞层 |
| 滴天髓 | 从名分（十神）转向气势（五行），几乎是一次范式替换 |
| 穷通宝鉴 | 连十神名分都不作为主判据，只看日干物性与月令气候 |

## 六、常见误读

1. **误读一：把它当「入门第一本」**。它是最早的系统著作，但不是为初学者写的操作手册；体例是论 + 口诀，且术语用法与今法有别。
2. **误读二：把「徐子平」当本书作者**。徐子平是术法源头，徐大升（或徐子升）才是编者，二者相隔年代与身份都不同。
3. **误读三：忽略明人合编**。今本五卷是明代合《渊海》《渊源》而成，讨论「宋本原貌」必须区分这一层。
4. **误读四：以后世旺衰扶抑解释其格局**。《渊海子平》说财官，重点在名分与格局组合，不是日主强弱平衡。

## 七、可继续深挖的方向

- 《渊海子平》卷五十干体象诗与《滴天髓》「论天干」的意象承继关系（任氏《命理索隐》曾把十神性质与甲乙木死木/活木之辨融合）。
- 卷四「十二月建候」与《穷通宝鉴》（栏江网系统）调候思想的源流关系；一说《栏江网》蓝本与《三命通会》卷十一「五行时地分野」相关。
- 《继善篇》《喜忌篇》在《子平真诠》卷三「附喜忌篇」中的引用与改写。
