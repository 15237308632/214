# 06 · 基础体系：干支、五行、十神、长生、合冲、纳音、神煞

> 本层是五书共享的「词汇表」。所有条目都已结构化到 `data/*.json`，本文只讲规则、出处与**异说**。

## 一、阴阳五行与四时

五行相生：木→火→土→金→水→木；相克：木→土、火→金、土→水、金→木、水→火。

**旺相休囚死**（以月令为基准，五书通用框架）：

| 季 | 旺 | 相 | 休 | 囚 | 死 |
|---|---|---|---|---|---|
| 春 | 木 | 火 | 水 | 金 | 土 |
| 夏 | 火 | 土 | 木 | 水 | 金 |
| 长夏 | 土 | 金 | 火 | 木 | 水 |
| 秋 | 金 | 水 | 土 | 火 | 木 |
| 冬 | 水 | 木 | 金 | 土 | 火 |

> 「当令者旺，我生者相，生我者休，克我者囚，我克者死」。这是判断得时与否的第一步，但**不等于**日主强弱结论——强弱还须合看地支根气（得地）与全局党势（得势）。

**天干五合**：甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火。《子平真诠·论十干合而不合》强调须辨「合而有制、合而化、合而去、争合妒合」——**合去与合来结果相反**。

**天干四冲**：甲庚、乙辛、丙壬、丁癸（方位对角）；戊己居中不入四冲。

**两条铁律**：
- **年以立春换**，不是正月初一；**月以「节」换**，不是「气」，也不是农历初一。本库由 `sxtwl` 历法库保证（测试已校验 2026-01-30 为乙巳年、2026-02-10 为丙午年）。
- 藏干分本气 / 中气 / 余气；《子平真诠》卷三附有「十二月令人元司令分野表」，各本分日用事略有出入（本库 v1.0 未收录，见 `10` 待办）。

## 四、十神（唯一推导规则）

以日干为「我」，看他干：

| 关系 | 同阴阳 | 异阴阳 |
|---|---|---|
| 同我 | 比肩 | 劫财 |
| 我生 | 食神 | 伤官 |
| 我克 | 偏财 | 正财 |
| 克我 | 七杀（偏官） | 正官 |
| 生我 | 偏印（枭） | 正印 |

`data/shishen.json` 的 10×10=100 格由该规则全量生成，并在测试中由独立实现交叉校验。

> **沈氏四吉四凶**：财、官、印、食为「善而顺用」，煞、伤、劫、刃为「不善而逆用」。但这是就**月令用神**立论，不是十神道德标签；《子平真诠》第 18、19 篇专门纠正这种读法。详见 `07`。

## 五、十二长生（生旺死绝）

十二阶段：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。

**阳干顺行、阴干逆行**；戊己土寄火宫（与丙丁同）：

| 干 | 长生 | 帝旺 | 干 | 长生 | 帝旺 |
|---|---|---|---|---|---|
| 甲 | 亥 | 卯 | 乙 | 午 | 寅 |
| 丙 / 戊 | 寅 | 午 | 丁 / 己 | 酉 | 巳 |
| 庚 | 巳 | 酉 | 辛 | 子 | 申 |
| 壬 | 申 | 子 | 癸 | 卯 | 亥 |

**异说（重要）**：
- 任铁樵《滴天髓阐微》指出长生沐浴是**假借形容之辞，不可执一**，并以命例辨析阴阳顺逆。
- 阴干是否逆行、土是否寄火宫，历代有争议。
- 因此本库把长生表定位为**检索与文献对照**，不作为旺衰判定的主依据。

## 六、地支作用关系

| 类 | 内容 |
|---|---|
| 六合 | 子丑土、寅亥木、卯戌火、辰酉金、巳申水、午未（日月） |
| 三合局 | 申子辰水、亥卯未木、寅午戌火、巳酉丑金 |
| 三会方 | 寅卯辰东方木、巳午未南方火、申酉戌西方金、亥子丑北方水 |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 |
| 相刑 | 寅巳申（无恩）、丑未戌（恃势）、子卯（无礼）、辰午酉亥自刑 |
| 六害 | 子未、丑午、寅巳、卯辰、申亥、酉戌 |
| 相破 | 子酉、卯午、辰丑、未戌、寅亥、巳申（各本有异） |

**成局条件**：三合、三会必须**三个不同地支齐备**，重复地支不算（如「午、午、未」不构成巳午未三会）。引擎已按此实现并写入测试。

**《子平真诠·论刑冲会合解法》的四个变式**（卷一第 7 篇）：
1. 因合而解冲（如子年午月，日坐丑，丑与子合解冲）。
2. **因解而反得刑冲**（合去其一，一合一刑）。
3. **会合不能解刑冲**（丑与巳酉会，子复冲午）。
4. **以刑冲解刑冲**（另位之刑冲解月令之刑冲，月官犹在，其格不破）。

> 沈氏结论是「如此之类，在人之变化而已」；《滴天髓·顺逆》则从气势角度说「势已成者不可逆」。两者是不同视角，不可互相套用。

## 七、六十甲子纳音与空亡

- 纳音 30 组×2 = 60 柱，如甲子乙丑海中金、丙寅丁卯炉中火……壬戌癸亥大海水。
- **六旬**：甲子、甲戌、甲申、甲午、甲辰、甲寅；空亡依次为戌亥、申酉、午未、辰巳、寅卯、子丑。
- 例：辛亥属甲辰旬，空亡寅卯。

**层位说明**：纳音是李虚中古法的核心，子平法兴起后降为辅参；任铁樵力斥纳音，《子平真诠·论星辰无关格局》亦不取。本库保留纳音仅为文献完整性，**不纳入主线判局**。

## 八、神煞

常用且起例明确者（`data/shensha.json`）：

| 起例 | 神煞 |
|---|---|
| 以日干 / 年干 | 天乙贵人、文昌、禄神、羊刃 |
| 以年支或日支三合局 | 驿马、桃花（咸池）、将星、华盖、劫煞、亡神 |
| 以月支 | 天德贵人、月德贵人 |
| 以日柱旬 | 空亡（见纳音表） |

例：天乙贵人「甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，庚辛逢虎马」；辛日天乙在寅午。

**三条限定**：
1. 《渊海子平》卷一、《三命通会》大量收录，属**古法层**；
2. 《子平真诠》第 21 篇「论星辰无关格局」、任铁樵《滴天髓阐微》明确反对以神煞定格局，属**子平层**；
3. **羊刃的阴干取法历代有异**（一作乙辰、丁未、己戌、辛丑、癸丑），本库取通行说法并在数据中标注。

因此本库把神煞定位为**辅助参断**，权重低于月令格局、旺衰与调候。

## 九、得时、得地、得势

| 概念 | 判据 |
|---|---|
| 得时 | 月令是否当旺 / 相（旺相休囚死） |
| 得地 | 地支是否有根（长生、临官、帝旺、墓库余气） |
| 得势 | 全局是否有党助（比劫、印绶透干或成局） |

《滴天髓》强调三者须合看，且「得时不旺、失时不弱」（《子平真诠》卷一第 6 篇专论）——**不能只看月令一项**。本库 `wuxing_profile` 的加权计数只是可视化辅助，不是典籍定法。
