# 07 · 十神与格局：月令八格的推演链

> 本篇以《子平真诠》为主轴。读之前请先确认一件事：**真诠说的「用神」是月令所定之格，不是扶抑用神**（见 `08`）。

## 一、从日干到十神，再到格局

```
日干(我) ──生克+阴阳──> 十神(名分)
月令地支 ──藏干透干──> 用神(格局)
四柱配合 ──成败/救应/相神──> 格局成立与否
```

《子平真诠·论用神》：

> 八字用神，专求月令，**以日干配月令地支，而生克不同，格局分焉**。财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。

沈氏随后批评「今人不知专主提纲，然后将四柱干支，字字统归月令」，并列出五种典型混淆：

| 见到的组合 | 俗解（误） | 正解（须先看月令） |
|---|---|---|
| 正官佩印 | 官印双全，与印绶用官同论 | 官格佩印护官 |
| 财透食神 | 食神生财 | 财格逢食生 |
| 偏印透食 | 枭神夺食 | 泄身之秀 |
| 煞逢食制而露印 | 煞印相生 | 去食护煞（印破了制） |
| 煞格逢刃 | 七煞制刃 | 刃可帮身敌煞 |

> 同一组字，格局归属取决于月令；不先定月令，后面全错。这是全书最核心的方法论。

## 二、顺用与逆用的具体配合

| 用神 | 顺 / 逆 | 配合 | 忌 |
|---|---|---|---|
| 财 | 顺 | 食神相生、生官护财 | 财轻比重、财透七煞 |
| 官 | 顺 | 透财相生、生印护官 | 伤克、刑冲 |
| 印 | 顺 | 官煞相生、劫财护印 | 印轻逢财 |
| 食 | 顺 | 身旺相生、生财护食 | 逢枭、生财露煞 |
| 七煞 | 逆 | 食神制伏 | 财印资扶、逢财无制 |
| 伤官 | 逆 | 佩印制伏、生财化伤 | 非金水而见官、佩印而伤轻身旺 |
| 阳刃 | 逆 | 官煞制伏 | 官煞俱无 |
| 月劫 | 逆 | 透官制伏、透食化劫 | 无财官而透煞印 |

**四吉神能破格 / 四凶神能成格**（卷二第 18、19 篇）：吉神若位置不当、被合被冲，反能破格；凶神若制得宜，反能成格。徐乐吾注说得更直白：

> 为我所喜，枭伤七煞，皆为吉神；犯我所忌，正官财印，同为恶物，不能执一而论。

## 三、定格次序（本库引擎实现）

1. 取月支藏干（本气 / 中气 / 余气）。
2. 看这些藏干是否**透出**于年、月、时干（日干除外）；优先取本气透出者。
3. 透出之干对应的十神即为格（如月令午中丁透 → 七杀格）。
4. 若藏干皆未透，以**月令本气**定格。
5. 若月令本气为比肩 / 劫财（建禄、月劫、阳刃），月令本身不可为用，须另取财官煞食透干会支，但仍以月令为主轴。

引擎 `geju_profile()` 只做到第 5 步，输出标注为「**初判**」。第 6 步起（相神、位置、刑冲会合、有情有力、清浊纯杂）须人工综合，程序不代裁。

## 四、成格、败格、带忌、救应

> 用神专寻月令，以四柱配之，必有成败……**成中有败，必是带忌；败中有成，全凭救应**。

| 格 | 成 | 败 |
|---|---|---|
| 官 | 官逢财印，又无刑冲破害 | 官逢伤克刑冲 |
| 财 | 财生官旺 / 财逢食生而身强带比 / 财格透印而位置妥贴 | 财轻比重 / 财透七煞 |
| 印 | 印轻逢煞 / 官印双全 / 身印两旺用食伤泄气 / 印多逢财而财透根轻 | 印轻逢财 / 身强印重而透煞 |
| 食 | 食神生财 / 食带煞无财，弃食就煞而透印 | 食神逢枭 / 生财露煞 |
| 煞 | 身强七煞逢制 | 七煞逢财无制 |
| 伤官 | 伤官生财 / 佩印而伤旺印有根 / 带煞无财 | 非金水而见官 / 生财带煞 / 佩印而伤轻身旺 |
| 阳刃 | 透官煞而露财印，不见伤官 | 阳刃无官煞 |
| 建禄月劫 | 透官逢财印 / 透财逢食伤 / 透煞遇制伏 | 无财官，透煞印 |

**相神**：护格成格之字。沈氏谓「伤相神甚于伤用神」。用神定名分，相神定成立；只找用神不找相神，是初学最常犯的错。

**格局高低**（第 12 篇）：由**有情 / 无情、有力 / 无力、清 / 浊、纯 / 杂**决定，不由十神吉凶一刀切。

## 五、几个专门议题

**杂气与墓库**（第 16、17 篇）：辰戌丑未为杂气，藏干多，取用须看透出与司令；「墓库刑冲之说」专纠「墓库必待冲而后发」的俗论。

**用神变化与纯杂**（第 10、11 篇）：透干不同、位置不同，格局可变化；清气浊气附论于第 11 篇，与《滴天髓》「清气」「浊气」专章可互参。

**外格用舍**（第 22 篇）：月令有用神则不取外格。卷五第 47、48 篇列曲直仁寿、化气、倒冲、朝阳、合禄、从财、从煞、井栏叉、遥合等杂格，态度审慎；《滴天髓》「从象、化象、假从、假化、顺局、反局」一系可对照阅读。

**行运**（第 25、26 篇）：论行运、论行运成格变格——原局成格之字被运伤则变格；第 27、28 篇「喜忌干支有别」「支中喜忌逢运透清」进一步区分干与支在岁运中的不同作用。

## 六、三套坐标系下的「同一个八字」

以甲木生子月为例，三种读法并列（见 `00` 与 `09`）：

| 体系 | 第一步 | 关注 |
|---|---|---|
| 真诠 | 子中癸水为印 → 印格 | 透否、是否被财破、官煞相生、相神 |
| 滴天髓 | 冬水寒凝，看气势流通 | 寒甚须暖，不拘财官印绶皆可为用 |
| 穷通 | 「木性生寒，丁先庚后，丙火为佐」 | 先解冻，再谈其余 |

> 三者可能给出不同用神。**先声明主用哪套，再用另两套校验**，不要平均。

## 七、常见误读清单

1. 把「用神」当扶抑用神 → 全书读反。
2. 把四吉四凶当标签 → 忽略第 18、19 篇。
3. 只看透干不看位置、合冲 → 忽略「有情有力」。
4. 只找用神不找相神 → 成格败格无从判断。
5. 月令本气为比劫仍硬按八格取 → 应走建禄月劫 / 阳刃一路。
6. 把徐乐吾评注的五类取用法、命例当作沈氏原文。
