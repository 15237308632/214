# 八字命理知识库 · 子平五经结构化研读库

> **定位与免责**：本库是对《渊海子平》《滴天髓》《三命通会》《子平真诠》《穷通宝鉴》五部中国传统术数典籍的**文献整理、概念结构与可计算工具**，供文献学、思想史、民俗学与文化研究参考。八字命理属于传统术数，**不是科学**，本库不宣称任何预测能力，不提供、也不构成人生、婚恋、医疗、法律、投资等方面的决策依据。库内所有「断语」「吉凶」均为古籍记录的转述，不代表本库立场。

---

## 这是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 五书的版本、篇章、核心命题与异说的对照考据 | 五书全文影印或点校本（原文获取渠道见 `docs/10-参考文献与版本考.md`） |
| 干支、五行、十神、十二长生、纳音、合冲刑害、神煞、格局、调候的**结构化数据** | 一套号称「算得准」的自动断命程序 |
| 由规则推导、可复现、可测试的排盘与检索引擎 | 替人下最终结论的黑箱 |
| 三套坐标系（格局 / 旺衰 / 调候）并置与分歧标注 | 把互相冲突的流派强行揉成一套「标准答案」 |

**核心设计决定**：五书并不共享同一套判局坐标。《子平真诠》以**月令格局**为经，《滴天髓》以**气机旺衰**为经，《穷通宝鉴》以**寒暖燥湿**为经。混用而不声明，是实务中最大的错误来源。因此本库**并列三说、逐处标注异说**，不代为裁决。

## 快速开始

```bash
pip3 install sxtwl                         # 寿星天文历：立春换年、节气换月、日柱
python3 src/build_data.py                  # 重新生成全部 data/*.json
python3 -m unittest discover -s tests -v  # 18 项校验
python3 src/cli.py --demo                  # 示例命例完整报告

# 由公历排盘（北京时间）
python3 src/cli.py --solar "1990-06-15 14:00" --sex 男

# 直接给定四柱
python3 src/cli.py --pillars "庚午 壬午 辛亥 乙未" --sex 男 --json out.json

# 查数据表
python3 src/cli.py --query 调候 甲 子
python3 src/cli.py --query 十神 甲 辛
python3 src/cli.py --query 长生 甲 子
python3 src/cli.py --query 纳音 甲子
python3 src/cli.py --query 书 子平真诠
python3 src/cli.py --list
```

浏览器打开 `index.html` 可离线查五书卡片、120 条调候、十神表、十二长生、六十甲子纳音。

## 判局次序（摘要，详见 `docs/09`）

1. **历法层**：立春换年、节换月、日柱、时柱（五鼠遁）；节气日须核对交节时刻。
2. **调候**：冬夏先寻水火，春秋再看燥湿 —— 《穷通宝鉴》。
3. **格局**：月令透干定格，审成败救应与**相神** —— 《子平真诠》。
4. **旺衰理气**：得时、得地、得势；衰旺真机、中和与流通 —— 《滴天髓》。
5. **辅助层**：神煞、纳音、六亲、宫位 —— 《渊海子平》《三命通会》。权重低于前三层。
6. **岁运**：大运顺逆（阳男阴女顺行）与流年引发。

> 《子平真诠·论星辰无关格局》与任铁樵《滴天髓阐微》都明确反对以神煞定格局；而《渊海子平》《三命通会》大量收录神煞。这不是「谁对谁错」，而是**古法与子平新法的层位差异**，读时须先分清自己在用哪一层。

## 数据层说明

所有 `data/*.json` 都由 `src/build_data.py` 从基础公理推导生成，不手抄：

- `shishen.json` 10×10=100 格，由「五行生克 + 阴阳同异」推导，测试中用独立实现交叉校验。
- `changsheng.json` 阳干顺行、阴干逆行，戊己寄火宫；`nayin.json` 六十甲子含旬空。
- `tiaohou.json` **10 干 × 12 月 = 120 条**《穷通宝鉴》取用提要原文，`text` 存原文，`yongshen候选` 为机器提取并已剔除日主，取用仍须读原文。
- `classics.json` 五书文献卡片，凡作者、卷数、成书年代有异说一律并列。

重新生成：`python3 src/build_data.py`；校验：`python3 -m unittest discover -s tests -v`。

## 精度与边界

| 层 | 精度 | 说明 |
|---|---|---|
| 干支历 | 高 | 由 `sxtwl` 提供，立春换年、节换月；**按日粒度取柱**，未纳入真太阳时与经度订正 |
| 十神 / 长生 / 纳音 / 合冲 / 神煞 / 调候检索 | 确定 | 规则推导，可复现、可测试 |
| 起运岁数 | 近似 | 传统「三日折一岁」，交节前后出生请复核精确时刻 |
| 格局 | 仅初判 | 只做月令透干定格；成格败格、相神、有情有力、清浊纯杂须人工综合 |
| 断语 | 不提供 | 引擎只输出结构化事实与古籍提要，不作吉凶结论 |

**子时换日**默认 23:00 归次日，可用 `late_zi=False` 切到晚子时派；两派日柱不同，报告中已标注。
